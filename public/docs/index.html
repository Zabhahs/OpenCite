OpenCITE · Developers

One call across papers, museums and archives

The OpenCITE API searches 250M+ open-access papers (OpenAlex, Crossref, DOAJ, PubMed) alongside library, museum, manuscript and Islamicate archives (Europeana, DPLA, Smithsonian, Gallica, Internet Archive, Open Library and more), deduplicates the results, labels each record with its source, and returns citations in MLA, APA, BibTeX, RIS and CSL-JSON. It also walks citation graphs and resolves DOI ↔ PMID ↔ PMCID. The same tools are available to AI assistants through the opencite-mcp server.

Contract v2 · OpenAPI 3.1 · base URL https://citation.today

1. Get a key

Sign in at citation.today → Developers and click Create key. The key is shown once. Free accounts get 20 credits a month; packs start at $10 for 2,000 calls and unlock the full source library.

2. Search

curl -H "x-api-key: oc_live_..." \
  "https://citation.today/api/search?q=ottoman+manuscripts&limit=25&cite=bibtex"
ParamMeaning
qQuery (required, ≤ 512 chars). Separate up to 5 terms with ; to run them all.
limitMax results, 1–100 (default 25).
citeExtra citation formats per result: bibtex,ris,csl-json (MLA and APA are always included).
formatjson (default) or a flat bibliography: mla, apa, bibtex, ris, csl-json.
sourcesComma-separated source ids to restrict to (as returned in source). Unknown ids are ignored.
authors1 to include author-name matches.

Response: { query, terms, coverage, count, totalCandidates, tookMs, results[], meta }. Each result carries id, source, title, authors, year, journal, doi, url, abstract, isOA, type, citedBy and citations. coverage is one of full · near-full · high · partial · limited; meta.creditsCharged and meta.balance tell you what the call cost.

3. Citation graph

curl -H "x-api-key: oc_live_..." \
  "https://citation.today/api/citations?id=10.1038/nature14539&dir=cited-by&limit=50&sort=impact"

dir=cited-by (works citing it) or dir=refs (its bibliography); id is a DOI or OpenAlex work id; minCitations filters citing works; sort is impact or year.

4. Resolve identifiers

curl -H "x-api-key: oc_live_..." \
  "https://citation.today/api/ids?ids=10.1038/nbt.3642,27571352,PMC5034905"

Any mix of DOIs, PMIDs and PMCIDs, up to 200. Returns { results: { [inputId]: { doi, pmid, pmcid } } }.

5. MCP (Claude Desktop, Cursor, any MCP client)

{
  "mcpServers": {
    "opencite": {
      "command": "npx",
      "args": ["-y", "opencite-mcp"],
      "env": { "OPENCITE_API_KEY": "oc_live_..." }
    }
  }
}

Tools: search_scholarly_sources, search_citations, resolve_ids.

Billing

  • 1 credit per call to any of the three endpoints, prorated by coverage: full 1.0 · near-full 0.99 · high 0.95 · partial 0.5 · limited free. Failed calls are never charged.
  • 402 with { code: "insufficient_credits", upgrade_url } when the balance is empty. 429 with Retry-After when rate limited (per key; and per IP before authentication).
  • Credits never expire. See the refund policy.

Errors

400Bad parameter (unknown format, too many terms, query too long).
401Missing or invalid x-api-key header. Keys are never accepted in the query string.
402Insufficient credits.
429Rate limited.
503No sources available right now (nothing was charged).

Every response carries X-OpenCITE-API-Version: 2. Breaking changes bump the version.
