Source licensing

What you may do with the metadata each source returns through the API. OpenCITE relays metadata and links; it does not redistribute full text. Per-work content licences, where the source states one, are on each card as evidence.license. Every API response lists the licences of the sources present under licenses. A source whose terms we have not confirmed is marked unknown — that is a statement of what we know, not a grant.
