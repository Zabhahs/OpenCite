# Capability Dossiers

> Full-spectrum capability dossiers, one per upstream API. Each follows the 14-section template in
> [[02-Adapters/Adapter-Capability-Tiers]] (Part 2). These document the **true API envelope** — every
> tag/field, metadata standard, query semantics, OA/free-access path, images, discipline tags,
> dirty-data hazards, and exploitation notes — so we can maximally mine each data stream.

See [[02-Adapters/Adapter-Capability-Tiers]] for the rubric, master matrix, and tier summary.
