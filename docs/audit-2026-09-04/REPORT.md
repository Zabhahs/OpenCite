## 0. Executive verdict (synthesizer)

OpenCITE today is a well-built free web app bolted to a paid API that no customer can reach: the only sellable thing (credits spent through an API key on /api/search, /api/citations, /api/ids and the MCP server) has no key-mint UI, no published package, no docs page, a pack rail that leaves buyers on plan=free, and a database that has been paused for roughly ten weeks on a Free-plan Supabase project with no backup anywhere else. Production is an unreproducible mid-sprint snapshot of the uncommitted v0.44 tree, and a single click on any of three open Dependabot PRs would overwrite it with the pre-teardown engine. The web subscriptions (Free/Student/Pro) sell quotas and sources the browser already gives away unmetered, so they cannot convert and their copy is false; Student is unpurchasable by construction. Pack pricing ($0.67-1.00 per 1k queries) is below OpenAlex's new metered cost, and the server runs OpenAlex keyless on a ~$0.10/day allowance that dies after ~50 all-tier queries. Traffic is zero, so the first dollar is a distribution event, not an engineering one; the engineering only has to stop a developer from bouncing off a dead sign-in, a 401, an empty result set, or a missing legal page. The single most important thing to do, today, is to resume Supabase OpenC_Auth and take an off-site dump before the 90-day one-click restore window closes (estimated 2026-09-15..22); everything else in this roadmap is moot if the ledger is lost. After that, the sequence is: freeze the deploy footgun and go Vercel Pro (same day), commit the exact tree prod runs so main==prod before touching any code (days 1-2), make the money path correct and honest (days 2-7), ship the Developers panel + legal pages + npm package (days 8-14), walk the whole journey with a real $10 charge on a second Google account (day 14), then spend days 15-30 putting a working Claude Desktop demo in front of ~30 named developers and researchers. Realistic 30-day effort is ~65-70 founder-hours with Claude Code, not the 54-59 the source plans claimed; the first external $10 pack is a day 21-35 outcome with an explicit day-30 decision gate on whether the pack SKU has any pull.

### legal-compliance (10 findings)

OpenCITE is not legally ready to charge money, and two issues can reverse revenue rather than merely block it. First, the site sells a Stripe checkout with zero customer-facing legal surface: /terms and /privacy resolve to the SPA shell (identical md5 to /), the Footer has no legal links, the ToS is a self-labelled DRAFT that says "do not link", and the Stripe checkout session sets no consent or policy links — this fails Stripe's website checklist (refund/cancellation policy, privacy policy, contact, currency) and makes every dispute a loss. Second, OpenAlex now meters API usage at $0.001 per search call (verified live: cost_usd 0.001 on both search= and title.search filters); every /api/search fans out two such calls (OPENALEX + CURATED) with no server OpenAlex key, so each sold query costs ~$0.002 upstream against $0.00067-$0.001 revenue. The 24-adapter serverSafe billable set was only ToS-reviewed for 5 sources; Internet Archive (scholarship/research only), BASE (non-commercial, key-gated), BnF (Etalab attribution), Thaqalayn (third-party scraper API of unlicensed texts) and relayed PubMed abstracts all conflict with an origin-blind paid resale.
